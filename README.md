# 🛍️ LUXE — Premium Store Website

LUXE is a modern luxury e-commerce frontend built using **HTML, CSS, and JavaScript**.  
It features a premium UI design, smooth animations, dynamic cart system, and responsive layout.

This project demonstrates a real-world fashion store interface with interactive user experience and modular JavaScript architecture.

---

## ✨ Features

- 🎨 Luxury dark-themed UI
- 🛒 Dynamic shopping cart system
- 🔎 Live product search overlay
- 📱 Fully responsive design
- 🧭 Mobile navigation menu
- ⭐ Product filtering by category
- 🔔 Toast notifications
- 🧾 Cart quantity management
- 🎯 Smooth scroll & reveal animations
- 🖱️ Custom cursor interaction

---

## 🧱 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6)**
- Google Fonts (Playfair Display & DM Sans)
